# Results provenance

Results generated by `scripts/run_benchmark.py` from repository root.

```bash
python scripts/run_benchmark.py \
  --models hgb logreg rf et gb ada gnb \
  --probability-calibrations none sigmoid isotonic \
  --output-dir results_v2 --jobs -1
```

Configuration: 15 OpenML datasets, 7 models, 3 calibration settings, 10 seeds
(`7, 19, 31, 42, 101, 202, 303, 404, 505, 606`), target `alpha=0.10`,
`C_FP=1`, `C_FN=10`, review costs `{0, 0.5, 1.0, 2.0}`. The runner writes
`run_manifest.json`, per-cell checkpoints, CSV summaries, and figures. It now
rejects any decreasing fixed-policy cost curve before rendering figures.

Calibration protocol: after the model/calibration/test split, the held-out
calibration pool is split into stratified selection and final-calibration
halves. Cost-controlled `alpha*` is selected using only the selection half.
Final Mondrian quantiles are fit only on the untouched final-calibration half.
The test split is used only for reporting.

Metric separation:

- `coverage_class_1`: ordinary set coverage, true label contained in set.
- `abstention_rate`: fraction with set cardinality not equal to one.
- `mean_cost`: decision cost under the stated review assumption.
- noisy-review tables: post-hoc cost sensitivity for fixed raw Mondrian masks.
- break-even table: dataset-level threshold against Bayes point cost.

Do not treat human-resolved deferrals as conformal coverage. Report them as
operational resolution metrics.
